#  MapnFix – Delivery Optimization Platform

MapnFix is a modern frontend web application designed to optimize delivery routes and improve logistics efficiency using a clean and user-friendly interface.

---

##  Features

* **Route Optimization**
  Find the most efficient delivery routes using smart algorithms.

*  **Accessibility Dashboard**
  Special interface designed for differently-abled delivery personnel.

*  **Mechanical Support**
  Quick assistance system to handle vehicle breakdowns.

*  **EV Tracking**
  Monitor deliveries using electric vehicles and reduce environmental impact.

*  **Signup with OTP (Demo)**
  Frontend-based OTP verification for user signup.
